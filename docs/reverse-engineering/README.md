# Ludo Atlas · 邪修·逆向工程

> 定位：一条不走正门的学习路线。正门是教程、文档与源码；邪修是把成品拆开，看它到底怎么运转。
> 写给想靠拆解来学习的人、做 Mod 和移植的人、想让老作品重新跑起来的人，以及要保护自己作品的人。

## 2. 为什么值得学

把已发布的作品当教材，是自学者手里最锋利、也最需要克制的一把刀。三个实在的收益：

- **看懂设计如何落地**：拆开一套存档或一份关卡数据，比读三篇教程更快理解「设计怎么变成实现」。
- **技术考古**：老作品在极小内存与算力里做出的取舍，是今天堆资源解决不了问题的对照样本。
- **互操作与保存**：旧作在新平台重跑、Mod、汉化与修复，全都建立在「读懂别人写的二进制」之上。

值得动用的时候：想学的对象没有源码；有源码但文档缺失；需要兼容或迁移；评估自己作品被拆解时的攻防面。

## 4. 第一周清单

1. **只选安全目标**：自己写的程序、开源游戏、官方支持 Mod 的作品、公开的教学靶场与 CTF 题目。
2. **装最小工具集**：反汇编器（Ghidra）、调试器（x64dbg）、文件识别（Detect It Easy）、十六进制编辑器（ImHex）；游戏内存入门用 Cheat Engine。
3. **做三个小实验**：改掉自己程序里的一个判定；用 Cheat Engine 改一个单机数值（自己的游戏或教学靶场）；把同一小段代码在 -O0 与 -O2 下的反汇编对照着读。
4. **三行记录法**：每个实验写下目标、过程、发现。邪修最怕的不是难，是漫无目的。

## 5. 目标的激进程度（由安全到危险）

1. 自己的作品与开源项目：随便拆，先练手。
2. 官方开放数据的作品（提供 Mod 工具链、公开文件格式）：按官方条款做。
3. 公开的教学靶场与逆向 CTF：合法且系统。
4. 一般商业成品：研究性质的静态阅读在多数地区属灰色地带，先读 §1 与《法务、专利与竞争手册》再决定；永远不要分发提取出的受版权资源。
5. 这里没有第 5 条：在线游戏的服务端与反作弊、他人的付费软件绕过、破解传播，不在本板块范围。

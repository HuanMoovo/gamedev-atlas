# Ludo Atlas · 邪修·逆向工程 · 实操路线

> 四周入门路线、三个迷你实验、一份常见坑清单。全部练习只使用自己的作品、开源游戏或公开教学靶场。
> 免责声明见《邪修·逆向工程》§1；工具安装见《工具链》。

---

## 1. 四周路线（每周 3-5 小时）

### 第 1 周：概念与准备

- 补四个概念：进制与字节序、文件魔数、内存与地址、调用栈。
- 认识一份可执行文件的结构（PE 或 ELF 都行，自己画一遍胜过看十遍）。
- 装好五件套：Ghidra、x64dbg、Detect It Easy、ImHex、Cheat Engine。
- 验收：能讲清一个 exe 从双击到进入 main 大致发生了什么。

### 第 2 周：静态分析

- 用 Ghidra 打开自己写的一个小程序（带几个函数与分支的那种）。
- 在 -O0 与 -O2 两个优化级别下各编译一次，对照反汇编找不同。
- 验收：能定位 main 与你写的目标函数，说清编译器各做了什么。

### 第 3 周：动态调试

- x64dbg：下断点、单步、看寄存器与内存；把第 2 周的程序在关键分支处断下来。
- Cheat Engine：在你自己写的（或教学靶场的）小游戏里改一个数值，从搜数值走到找到基址。
- 验收：能写下「值存在哪里、为什么改它游戏会变」。

### 第 4 周：数据与资源

- 拆一个开源游戏的数据文件（Godot 开源项目或你自制的资源包）。
- 写一个 30 行左右的 Python 脚本，把其中一列数据读出来。
- 验收：脚本跑通，能解释格式里每个字段的含义。

## 2. 三个迷你实验（可照做）

**实验一：给自己程序打个补丁**

1. 写一个带「完整版 / 试用版」开关的小程序；
2. 在 Ghidra 里找到判定分支；
3. 算出要修改的字节并写回一个副本；
4. 运行验证行为变化。

验收：能写出「改前指令、改后指令、行为差异」三行表。

**实验二：函数级对照阅读**

挑一个熟悉的算法（比如冒泡排序），在 -O0、-O1、-O2 下各编译一次，对照三份反汇编，说出每级优化删掉了什么。
验收：三份汇编各写一行总结。

**实验三：资源提取小工具**

对开源游戏（或其示例素材）写一个小工具：扫描目录、按文件头识别格式、导出内嵌图片。
验收：工具能对两种不同格式给出正确结果。

## 3. 常见坑

- **目标太大**：第一周就想拆大制作。先定一个具体问题，比如「这个存档里的金币存在哪」。
- **装备党**：工具装了一堆，每件用不过一小时。五件套用熟再换。
- **过早上对抗**：反调试、壳与虚拟机保护是另一个领域，先把无保护目标练到手熟。
- **红线三条**：不碰盗版资源、不绕过技术保护措施、不做外挂与破解分发（详见 §1 与《法务、专利与竞争手册》）。
- **只拆不记**：用三行记录法；一周后回顾，才知道自己学到了什么。
- **孤军深入**：卡超过两小时就换角度，或带上做过什么去社区提问。

## 4. 进阶方向

- **引擎专项**：Unity（IL2CPP 路线）、Unreal（蓝图与资产）、Godot（gdsdecomp），工具见《工具链》§5。
- **安全研究**：CTF 是最系统的练习场，赛事日历见 [CTFtime](https://ctftime.org)，闯关课程见 [pwn.college](https://pwn.college)。
- **保护自己的作品**：完整性校验、代码混淆、服务端权威；知攻才知守。
- **汉化与本地化工程**：文本提取、字库替换、回填与回归，可与《本地化管线》的流程相接。
